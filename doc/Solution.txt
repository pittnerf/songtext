Deploy size too large: --jpeg-quality 80
Example:

python3 9_songtext/scripts/build_songs.py --scale 2.5 --jpeg-quality 85

1. Enable GitHub Pages
On GitHub → songtext → Settings → Pages:

Build and deployment → Source: GitHub Actions
2. Check the deploy workflow
Go to Actions → Deploy to GitHub Pages — it should run automatically from your push. Wait until it shows green.
